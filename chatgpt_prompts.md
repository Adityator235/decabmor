## ChatGPT Tips

1. **Generate in ChatGPT Plus** (DALL-E 3) — free tier uses DALL-E 4 which is worse for clean infographics
2. **If the image has too much detail**, reply: "Make it simpler, more minimal, with more white space"
3. **If ChatGPT adds text to the image**, reply: "Regenerate but do not include any text or words in the image, only placeholder lines"
4. **For consistency**, generate all images in the same ChatGPT thread so it remembers the style
5. **If colors are off**, add: "Use exactly these colors: teal #5BB5A2, green #2D5F3E, gold #D4913C, white background"
6. **Save each image** as `page_01.png` through `page_20.png`
