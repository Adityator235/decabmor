## Notes for Generation

1. **All images should be 1920×1080 (16:9)** — standard presentation aspect ratio
2. **Leave negative space** — each prompt specifies where text should go; the AI image generator needs empty areas
3. **No text in generated images** — all labels should be placeholder lines; actual text is added separately
4. **Color consistency** — if the AI doesn't respect the teal/green palette, you can tint images afterward in any editor
5. **Test with DALL-E 3** (ChatGPT Plus) or Midjourney for best results. DALL-E handles "leave blank space" instructions better
6. **If an image turns out too busy**, regenerate with the added instruction: "minimalist, lots of white space, no clutter"
